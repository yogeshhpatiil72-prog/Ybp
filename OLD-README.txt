PATILNEO ADMIN PANEL - DEMO
1. Extract this ZIP.
2. Upload/replace index.html, style.css, script.js, README.txt, movies.json in the ROOT of your existing GitHub repository.
3. Upload admin.html to that same root.
4. Commit changes and wait for GitHub Pages to update.
5. Open: https://yogeshhpatiil72-prog.github.io/Patil-neo/admin.html

IMPORTANT LIMITATION:
This starter admin page stores added entries in localStorage in the same browser only. It does NOT publish them to all visitors or securely protect admin access. For a true shared catalogue and secure admin login, a database/backend (e.g. Firebase) must be configured. Use only content you own or are licensed to distribute.
